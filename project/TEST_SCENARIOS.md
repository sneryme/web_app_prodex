## Данные для FR-01…FR-04, FR-06…FR-08

Эти тесты бьют по реальному участнику-flow и требуют двух сид-команд backend (см. `README.md`):

```bash
python manage.py seed_demo_organization     # создаёт Organization с entry_code=demo-entry-code
python manage.py seed_real_questionnaires   # загружает реальные EQ-5D/HADS/Спилбергер–Ханин и делает их активным комплектом
```

Старая команда `seed_dummy_questionnaire` (упрощённый опросник из 6 вопросов, без реальных
ключей/границ зон) всё ещё существует для быстрой проверки маршрута без реальных данных, но
больше не используется по умолчанию — `seed_real_questionnaires` деактивирует её комплект.

## Как добавить сценарий

1. Добавьте строку в таблицу выше с новым ID.
2. Добавьте `scenario("FR-NN.M", "…")` в `e2e/tests/fr-NN-*.spec.ts`.
3. Когда функциональность реализована, замените `scenario(...)` на `test(...)` с реальными шагами и поставьте ✅.

## Запуск

```bash
cd e2e
npm install
npx playwright install chromium
npm test            # desktop + mobile
npm run test:ui     # с окном Playwright
npm run report      # HTML-отчёт
```

Перед запуском проект должен работать (`docker compose up`). Адреса можно переопределить: `E2E_BASE_URL` (по умолчанию `http://localhost:5173`) и `E2E_API_URL` (по умолчанию `http://localhost:8000/api`).
