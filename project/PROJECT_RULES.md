# Правила проекта

## Обязательные правила

1. Не считать результат медицинским диагнозом или индивидуальной рекомендацией.
2. Не объединять EQ-5D, HADS и Спилбергера–Ханина в произвольный индекс.
3. Не хранить прямые идентификаторы участника в тестовом контуре MVP.
4. Работодатель получает только агрегированные данные; малые группы скрываются.
5. Любая методика, порог, текст интерпретации и версия опросника проходят методологическое подтверждение.
6. Согласие на обработку персональных данных хранится отдельно от иных подтверждений.
7. Все изменения API и схемы данных сопровождаются миграцией, тестом и записью в changelog.
8. Секреты не коммитятся; локальные значения живут в `.env`.
9. Frontend участника mobile-first, employer и admin контуры разделены.

## Definition of Done

- Есть acceptance criteria и тесты для изменённого поведения.
- Пройдены `docker compose config`, backend checks и frontend typecheck/build.
- Обновлены соответствующие спецификации.
- Проверено, что в логах и экспортируемых данных нет индивидуальных ответов для работодателя.
